# Signal Board — Abbreviation Glossary

| Code | Meaning |
|------|---------|
| WR | Win rate (%) |
| WV | Win volume (count) |
| WP | Win points (ECN pts) |
| WP/w | Win points per week |
| WP/m | Win points per month |
| WP/yr | Win points per year |
| WP/t | Win points total (cumulative) |
| W%/w | Win % gain per week |
| W%/m | Win % gain per month |
| W%/yr | Win % gain per year |
| W%/t | Win % gain total (cumulative) |

**Notes:**
- ~ prefix = estimated/average value
- (Avg.) = alternative label for estimates
- All public posts use codes only; full meanings here only
- ECN points: 1 pip = 10 pts; $0.10/pt at 0.1 lot EURUSD
